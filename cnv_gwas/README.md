# cnv_gwas: rare-CNV GWAS and gene-dosage axes of height and BMI (UK Biobank, All of Us)

Branch `cnv-gwas` of cnv-growth-bmi. One code base (`cnv_anthro/`), one JSON config per cohort.

**2026-11-16: the current code and the All of Us run for the Sacks 2026 drafts are in [`../AllOfUs/`](../AllOfUs/README.md).** It covers the CNV GWAS (this folder), plus the genome-wide burden, univariate grid, joint models, additivity, the meta-analysis and the figures. This folder is kept as the record of the 2026-11-15 UKBB analysis.

- **Task A**: probe-level CNV GWAS and allele-level tests at the Table S9 loci, adapted to quantitative traits (exact OLS).
  The probe model, probes, filters, independent-test count, genome-wide threshold and allele calling are ports of
  **Omar Shanta's PGC CNV cross-disorder GWAS code** (PGC CNV Freeze_2024; `IndividualDisorder/Freeze_2024/scripts/ALL/<DIS>/noFam_noSex`,
  `META_noSex`, `scripts_figures/scripts_trumpet_noSex`). The re-implementation reproduces his current SCZ probe results and Table S9 exactly (`replication/`).
- **Task B**: person-level burden of the ConGA gene-dosage axes (mirror, constraint; Engchuan et al., companion manuscript), genome-shift null,
  leave-one-locus-out over the 18 recurrent loci and an all-loci-removed run (`conga_axes_qt.py`); univariate grid and joint model (`conga_grid_qt.py`).
- **All of Us**: `configs/aou_workbench.json`, `workbench/` (notebook + dsub), adapters `aou_sv_to_cnv.py`, `aou_pheno_extract.py`.

Start with `cnv_anthro/README.md` (methods, validation, speed) and `HANDOFF_UKBB_anthro_CNV.md` (where everything lives on Expanse).

| folder | contents |
|---|---|
| `cnv_anthro/` | code, configs, grid designs, AoU workbench files, tests (synthetic test data are regenerated by `tests/make_synthetic_aou.py`) |
| `jobs/` | Expanse SLURM templates (frozen-snapshot pattern; 2-node ind-compute task runner) |
| `replication/` | scripts reproducing Omar's SCZ probe results and Table S9 (their outputs are unpublished PGC results and are not included) |
| `aggregates/ukbb/` | UKBB aggregate outputs only (summary tables, lead loci, axis summaries, Miami plots) |
| `scripts/id_scan.sh` | run before every push |

Data rules: no individual-level files here. PGC/UKBB individual data stay on Expanse; AoU data stay in the Workbench and only
`export_aggregate/` output (no counts 1-20) may be added under `aggregates/aou/`. Resources not included (public, large): refGene exons
(hg38_refGene_20200708), GeneBayes s_het gene covariates, TWAS30 FUSION files, ClinGen gene curation list, segDups; paths in the configs.
